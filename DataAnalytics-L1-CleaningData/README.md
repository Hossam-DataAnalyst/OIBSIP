# Titanic Data Cleaning Project 🚢

## 📌 Overview
This project is part of the **Oasis Infobyte Data Analytics Internship**. It focuses on cleaning and preprocessing the famous Titanic dataset using Python and Pandas to prepare it for Exploratory Data Analysis (EDA).

## 🛠️ Objectives
- **Handling Missing Values:** Filled missing values in the `Age` and `Embarked` columns using statistical methods (median and mode).
- **Data Reduction:** Dropped columns with excessive missing data or irrelevant information (e.g., `Cabin`).
- **Data Integrity:** Ensured all data types are correct and the dataset is free of inconsistencies.

## 💻 Tools & Libraries Used
- Python 🐍
- Pandas 🐼
- Google Colab / Jupyter Notebook 📓

## 📁 Files in this Repository
- `Titanic_Data_Cleaning.ipynb`: The notebook containing the step-by-step Python code for data cleaning.
- `cleaned_titanic_data.csv`: The final, clean dataset ready for analysis.

## 🚀 Conclusion
The dataset is now fully cleaned, with no null values in critical columns, making it ready for further analysis or Machine Learning modeling.
